МОСТЫ В БУДУЩЕЕ — ДЕМОНСТРАЦИОННЫЙ САЙТ

Как открыть
1. Откройте файл index.html в браузере.
2. Для показа лучше использовать полноэкранный режим браузера.
3. Интернет для работы страницы не требуется.

Состав
- index.html — содержание и структура;
- style.css — дизайн и адаптивная версия;
- script.js — анимации, мобильное меню и индикатор прокрутки.
- assets/hero-video.mp4 — 10-секундный фильм-концепция;
- assets/hero-poster.png — заставка фильма и исходный логотип;
- assets/logo-mark.png — подготовленный прозрачный знак для интерфейса.

Видео
- запускается кнопкой «Смотреть фильм»;
- после запуска доступны стандартные элементы управления и полноэкранный режим;
- если браузер запрещает автоматический запуск звука, ролик откроется без звука,
  который можно включить в панели управления.

Перед публичной публикацией необходимо подтвердить
- окончательную формулировку учредителей и организаторов премии;
- названия и описания номинаций;
- даты первого цикла;
- форму и размер поддержки лауреатов;
- официальный контакт;
- официальный логотип и перечень партнёров.

Текущая версия предназначена для презентации концепции, а не для приёма заявок.
